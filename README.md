# OmniInbox

微信小程序「Obsidian拾微同步」的记录单向同步到 Obsidian，写入位置与主页「快速记录」一致。同步方向为 微信 → Obsidian，不写回小程序。

## 安装

1. 下载本仓库的 `main.js`、`manifest.json`、`styles.css`。
2. 放入笔记库 `.obsidian/plugins/omniinbox/`。
3. 在 Obsidian「设置 → 第三方插件」中启用 OmniInbox。

## 配置

| 配置项 | 说明 |
| --- | --- |
| Obsidian 绑定 | 生成 6 位绑定码，填入小程序设置页完成连接 |
| 设备名称 | 绑定时显示的电脑名称 |
| 服务器地址 / 同步目录 | WebDAV 地址与远端投递目录，默认 `obsidian-omniinbox` |
| 账号 / 应用密码 | WebDAV 凭据，仅保存在本机 |
| 同步位置 | 随记、灵感、备忘录、日记目录、每日待办的路径模板，支持 `{Y}` `{M}` `{D}` 占位符 |
| 自动同步间隔 | 单位分钟，0 表示关闭 |
| 状态栏 | 显示最近同步时间 |

首次启用后，Obsidian 会在插件目录生成 `data.json` 保存上述设置；该文件不随插件发布。

## 投递格式

远端同步目录中每个投递为一个 JSON 文件，文件名形如 `note__20261126143000-1-ab12.json`：

- `type`：`note` / `idea` / `memo` / `thino` / `todo` / `nextday`
- `id`：唯一标识
- `createdAt`：毫秒时间戳
- `text`：正文
- `bindCode`：绑定后校验
- `dueDate`：`nextday` 类型的到期日

写入成功后删除远端文件。

## 写入规则

- 随记 / 灵感 / 备忘录：一级时间戳 + 标签 + `#微信收集`，正文按 Markdown 层级转为 Tab 缩进列表。
- Thino：`HH:mm` 时间戳 + Tab 缩进正文 + `#微信收集`。
- 待办：`- [ ] 内容 #每日待办 📅 日期`，写入当天每日待办。
- 次日待办：暂存于 `pendingNext`，到期日当天首次打开时转为待办。

去重依靠正文中的行内标志 `⟦wx:<id>⟧`（Obsidian 中渲染为注释），不依赖额外状态文件，也不改动手写正文。

## 命令

- `立即同步`：手动拉取一次。
- `处理明日待办`：手动处理到期的暂存待办。
